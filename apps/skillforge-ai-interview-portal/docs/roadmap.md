# SkillForge Roadmap

## Phase 1: Homelab MVP

- Role tracks for Platform Engineering, DevSecOps, and AI Infrastructure.
- Scenario-based technical challenges.
- Text-answer scoring with rubric and keyword fallback.
- Optional Ollama-based feedback.
- Video recording in browser and upload to API PVC.
- Kubernetes manifests with Postgres, API, web frontend, ingress, NodePort, and Argo CD application.

## Phase 2: HackerRank-style coding

- Safe code judge service.
- Timed assessments.
- Test case authoring.
- Candidate score history.
- Per-topic progress tracking.
- GitHub import for challenge answers.

## Phase 3: Micro1-style AI interviewer

- AI avatar or voice assistant.
- Speech-to-text transcription.
- Adaptive follow-up questions.
- Role-specific interview blueprint generation.
- Final structured report with strengths, gaps, and next practice plan.

## Phase 4: Production-grade platform engineering

- External Secrets integration.
- SSO/OIDC.
- NetworkPolicies.
- Prometheus metrics.
- Loki logs.
- OpenTelemetry tracing.
- Velero or S3 backup plan.
- Argo CD app-of-apps.
