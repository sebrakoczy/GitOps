# SkillForge v0.2 Product Upgrade

This release turns the MVP into a more serious platform engineering interview-prep product.

## What changed

- Expanded the bundled question bank to **432 interview questions** across **24 domains**.
- Expanded labs to **48 senior scenario labs**.
- Added repeatable content upsert on API startup, so existing databases receive new questions without wiping attempts/submissions.
- Reworked the UI into a clean HackerRank-inspired light theme with green accents.
- Added difficulty filtering and larger API query limits.
- Updated homelab NodePort to `32081`.
- Added optional Cilium allow policy for LAN access to the web pod.
- Kept static grading as the safe default until the isolated Kubernetes job runner is hardened.

## Upgrade commands

Build and push the new images:

```bash
REGISTRY=ghcr.io/sebrakoczy \
VERSION=0.2.0 \
PLATFORM=linux/amd64 \
./scripts/build-and-push.sh
```

Redeploy on the homelab:

```bash
helm upgrade --install skillforge ./deploy/helm/skillforge \
  --namespace skillforge \
  -f ./deploy/helm/skillforge/values-homelab-nodeport.yaml \
  --set imagePullSecrets[0].name=ghcr-pull
```

Verify:

```bash
kubectl -n skillforge get pods,svc,pvc
curl -s http://192.168.1.100:32081/api/health; echo
```

The API seed routine will upsert the new content during startup.

## Important product direction

The next production-grade releases should add:

1. Real user accounts and progress history.
2. Rich rubrics with score breakdowns.
3. AI-assisted mock interviews and follow-up questions.
4. Fully isolated challenge execution with per-submission Kubernetes Jobs.
5. Postgres migrations using Alembic.
6. OpenTelemetry tracing, Prometheus metrics, and structured logs.
7. Tenant/org model and Stripe billing if this becomes SaaS.
8. Auth via OIDC/GitHub/Google, then enterprise SSO.
9. Admin content editor and versioned question packs.
10. Anti-abuse controls for public challenge execution.
